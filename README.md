### 1. 🏥 HealthForecastAI — Hospital Readmission Prediction & Patient Risk Intelligence System

**Technologies:** Python, Machine Learning, FastAPI, Next.js, Tailwind CSS, Database Integration

An intelligent healthcare project designed to predict hospital readmissions, identify high-risk patients, evaluate treatment effectiveness, and support proactive care planning.

**Key features:**
- Patient data management and risk prediction.
- Treatment effectiveness analysis.
- Clinical decision support.
- Healthcare analytics dashboard.
- Role-based access for doctors, hospital administrators, researchers, and system administrators.
- AI model management and prediction API integration.

**Goal:** Support data-driven healthcare decisions and help healthcare professionals identify patients who may need additional attention.

### 2. 🎓 Digital Certificate Management System

**Technologies:** Web Development, Database Management, Backend Development

A digital system designed to simplify certificate-related processes and improve the organization and accessibility of certificate records.

**Key features:**
- Digital certificate record management.
- Organized storage and retrieval of certificate information.
- Streamlined certificate-related workflows.
- Database-driven application functionality.

### 3. 📝 Digital Outpass Management System

**Technologies:** React, Node.js, JavaScript, Database Integration

A web application designed to digitize the process of requesting, reviewing, and approving student outpasses.

**Key features:**
- Digital outpass request submission.
- Administrative approval and cancellation.
- Request status management.
- Backend API integration.
- Scope for automated status notifications.

### 4. 👁️ Object Detection for Blind People

**Technologies:** Python, OpenCV, Computer Vision, IoT

An assistive technology project intended to help visually impaired people identify objects in their surroundings.

**Key features:**
- Image-based object detection.
- Computer vision-based environmental awareness.
- Potential integration with audio feedback and assistive hardware.

**Goal:** Explore how computer vision and assistive technology can improve accessibility and independence.

### 5. 🚗 Smart Car Parking System

**Technologies:** Python, IoT Sensors, Arduino, Web Technologies

**Key features:**
- Parking occupancy detection.
- Sensor-based monitoring.

### 6. 🏍️ Rent2Ride — Online Bike Rental Platform
